Directorio de Proveedores • SENA CIMM

Gestión descentralizada de aliados comerciales, distribuidores y fabricantes mediante persistencia JPA con Hibernate 6 y relaciones muchos a muchos (@ManyToMany).

🎓 SENA Regional Boyacá 📍 CIMM Sogamoso

⚡ Arquitectura & Stack

  • Java 17 LTS Jakarta Persistence API (JPA)
  • Hibernate ORM 6.5 Mapeo @ManyToMany con JoinTable
  • MySQL 8.0 Community Tabla pivote productos_proveedores
  • Micro-Servidor HTTP Endpoints REST nativos JSON

🔗 Mapeos JPA / ORM

  • @ManyToMany
    Proveedor ⇄ Producto JoinTable: productos_proveedores
  • @ManyToOne
    Producto ➔ Categoria FK: categoria_id
  • @OneToOne
    Producto ➔ FichaNutricional FK: ficha_nutricional_id
