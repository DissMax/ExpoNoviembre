Tecnólogo ADSO • SENA CIMM

Solución integral de inventario comercial con arquitectura limpia por capas en Java 17, mapeo objeto-relacional declarativo con Hibernate 6 y persistencia en motor relacional MySQL 8.

🎓 SENA Regional Boyacá 📍 CIMM Sogamoso

⚡ Arquitectura & Stack

  • Java 17 LTS Jakarta Persistence API (JPA)
  • Hibernate ORM 6.5 Pool HikariCP de alto rendimiento
  • MySQL 8.0 Community Transacciones ACID & Claves foráneas
  • Micro-Servidor HTTP Endpoints REST nativos JSON

🔗 Mapeos JPA / ORM

  • @ManyToOne
    Producto ➔ Categoria FK: categoria_id
  • @OneToOne
    Producto ➔ FichaNutricional FK: ficha_nutricional_id
  • @ManyToMany
    Producto ⇄ Proveedores Tabla pivote: productos_proveedores
